📚 Curso_Alura

Repositório com exercícios, projetos e práticas realizadas durante cursos da Alura, organizado para facilitar o estudo, a consulta e a evolução contínua em programação.

🧠 Sobre o projeto

Este repositório reúne todo o material desenvolvido ao longo dos cursos da Alura, incluindo códigos, exemplos, desafios e pequenos projetos.
Ele serve como um portfólio de aprendizado e também como base de consulta para revisões futuras.

🎯 Objetivo

Consolidar conhecimentos em desenvolvimento web e programação

Praticar conceitos aprendidos nos cursos
